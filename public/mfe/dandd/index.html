Grimório de Classes

Projeto acadêmico em Vue 3 que consome a D&D 5e SRD API para exibir as 12 classes jogáveis do sistema de regras D&D 5ª edição (SRD 2014).

Vue 3 TypeScript Vue Router Tailwind CSS 4 Vite

O que o projeto faz

  • Listagem das 12 classes em um grid responsivo, cada uma com cor e ícone temáticos.
  • Busca em tempo real por nome, em português ou em inglês.
  • Página de detalhes com dado de vida, salvaguardas, proficiências, subclasses e informações de conjuração.
  • Interface totalmente em português do Brasil, incluindo os dados que vêm da API.

Tema escuro, de RPG medieval, substituindo a tradicional Pokédex por um compêndio de aventureiros.

A API que o projeto consome

Esta amostra chama a mesma D&D 5e SRD API (versão 2014) e mostra os dados como ela os entrega, no idioma que o navegador pede. Não é o aplicativo em si.
