Nexus CRM

Painel de gestão de projetos e tarefas feito com Angular e Tailwind CSS.

Angular 22 TypeScript 6 Tailwind CSS 4 Three.js Vitest 5

O que o projeto faz

  • Tela de login com uma cidade 3D animada em Three.js ao fundo.
  • Painel inicial com indicadores, quadro de tarefas, detalhes e comentários.
  • Lista de projetos com progresso e página de detalhes de cada projeto.
  • Tema claro e escuro, alternados com um clique.
  • Carregamento com skeleton, sem telas em branco enquanto os dados chegam.
  • Navegação por teclado e layout responsivo a partir de 320 px.

Os dados do projeto são simulados (mocks): ainda não há backend.

Organização do código

src/app/
├── core/       serviços, guards, modelos e mocks
├── shared/     componentes de UI reutilizáveis
└── features/   telas por domínio
    ├── auth/       login + cena 3D
    ├── home/       painel e tarefas
    └── projects/   lista e detalhes de projetos

O repositório também traz documentos de arquitetura, design system e guia de desenvolvimento.

Rodando localmente

Pré-requisito: Node.js 22 ou superior.

git clone https://github.com/gaboel0/Nexus-CRM.git
cd Nexus-CRM
npm install
npm start

O README lista ainda npm run build, os testes unitários com Vitest e a checagem de formatação com Prettier.
