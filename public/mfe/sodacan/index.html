Soda Can

Uma animação fluida e simples com duas bebidas diferentes, feita com HTML e CSS.

HTML CSS JavaScript puro Sem dependências

O que o projeto faz

  • Mostra duas latas lado a lado, cada uma com a imagem de uma bebida diferente.
  • Ao passar o mouse sobre as latas, a animação é disparada.
  • É um projeto pequeno e estático: uma página, uma folha de estilo e as imagens.

Na aba "Projeto rodando" você vê a animação em ação: passe o mouse sobre as latas.

Como a animação é montada

  • Cada lata é um elemento .lata, e a imagem da bebida entra por uma variável CSS (--url).
  • Um pequeno script escuta mouseenter e mouseleave no bloco das latas e liga ou desliga a classe hover no body.
  • O CSS reage a essa classe para animar as latas, sem nenhuma biblioteca.
produto.addEventListener('mouseenter', () => body.classList.add('hover'))
produto.addEventListener('mouseleave', () => body.classList.remove('hover'))

Rodando localmente

Por ser uma página estática, não há instalação: basta abrir o index.html do repositório no navegador.
